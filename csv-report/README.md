# CSV Report Generator

Утилита читает CSV, определяет распространённую кодировку и разделитель, анализирует заполненность и числовые значения, затем создаёт автономный HTML-отчёт.

## Что попадает в отчёт

- количество строк и столбцов;
- тип каждого столбца: число или текст;
- количество заполненных, пропущенных и уникальных значений;
- минимум, максимум и среднее для числовых столбцов;
- предпросмотр первых десяти строк.

Поддерживаются кодировки UTF-8 с BOM, UTF-8 и CP1251, а также разделители `,`, `;` и табуляция. Значения из CSV экранируются перед вставкой в HTML.

## Запуск

Из корня портфолио:

```powershell
py -3 csv-report/report.py csv-report/demo/sales.csv --output csv-report/demo-report.html
start csv-report/demo-report.html
```

Из папки `csv-report`:

```powershell
py -3 report.py demo/sales.csv --output report.html
start report.html
```

Для быстрой проверки в репозитории уже лежат [пример CSV](demo/sales.csv) и [готовый HTML-отчёт](demo-report.html).

## Тесты

```powershell
py -3 -m unittest discover -s csv-report/tests -v
```

Ограничение текущей версии: весь CSV загружается в память, поэтому утилита рассчитана на небольшие и средние файлы, а не на многогигабайтные наборы данных.
