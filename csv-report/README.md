# CSV Report Generator

Утилита читает CSV, определяет разделитель и кодировку, анализирует заполненность и числовые значения, затем создаёт автономный HTML-отчёт.

## Запуск

```powershell
python report.py demo/sales.csv --output report.html
start report.html
```

Отчёт открывается в любом современном браузере и не требует интернета.
