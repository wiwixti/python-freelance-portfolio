# Safe File Organizer

Консольная утилита сортирует файлы в выбранной папке по категориям. По умолчанию она только показывает план: данные не меняются, пока пользователь явно не добавит `--apply`.

## Безопасность

- режим предпросмотра включён по умолчанию;
- одноимённые файлы не перезаписываются — добавляется суффикс `_1`, `_2` и далее;
- выполненная сортировка записывается в `organizer_manifest.json`;
- команда `--undo` возвращает файлы на исходные места;
- при ошибке посреди операции уже сделанные перемещения автоматически откатываются.

## Запуск

Команды из корня портфолио:

```powershell
# Только посмотреть план
py -3 file-organizer/organizer.py "$env:USERPROFILE\Downloads"

# Выполнить показанную сортировку
py -3 file-organizer/organizer.py "$env:USERPROFILE\Downloads" --apply

# Отменить последнюю сортировку
py -3 file-organizer/organizer.py "$env:USERPROFILE\Downloads" --undo
```

Пример безопасного предпросмотра:

```text
План сортировки:
  photo.jpg -> Images/
  report.pdf -> Documents/

Предпросмотр завершён. Для выполнения добавьте --apply
```

## Категории

Изображения, документы, таблицы, архивы, аудио, видео и код раскладываются по отдельным папкам. Неизвестные расширения попадают в `Other`. Подпапки не обходятся: обрабатываются только файлы верхнего уровня выбранной папки.

## Тесты

```powershell
py -3 -m unittest discover -s file-organizer/tests -v
```

Для первой проверки лучше использовать специально созданную тестовую папку, а не единственную копию важных документов.
