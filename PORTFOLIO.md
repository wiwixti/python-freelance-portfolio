# Портфолио Python-разработчика

Я создаю небольшие программы, которые убирают ручную рутину: сортируют файлы, обрабатывают таблицы, формируют отчёты и показывают состояние компьютера.

## Что могу сделать для заказчика

- автоматизировать повторяющуюся работу с файлами и папками;
- обработать CSV-данные и сформировать понятный отчёт;
- написать небольшую программу с графическим интерфейсом для Windows;
- доработать существующий Python-скрипт;
- найти и исправить ошибку, добавить журналирование и проверки.

## Проекты

### 1. Windows Resource Monitor

Оконная программа без сторонних зависимостей. Получает системные показатели через Windows API, обновляет их каждую секунду и сохраняет историю в CSV.

**Практическая ценность:** контроль нагрузки и сбор данных для первичной диагностики медленного компьютера.

**Надёжность:** ошибки чтения системных данных отображаются в окне; история ограничена последними 60 минутами и не растёт бесконечно.

### 2. Safe File Organizer

Сортирует содержимое папки по категориям. Перед изменениями показывает план, не перезаписывает одноимённые файлы и умеет отменять последнюю операцию.

**Практическая ценность:** безопасная уборка папок Downloads, Desktop и рабочих каталогов.

**Надёжность:** реальное перемещение выполняется только с флагом `--apply`; при ошибке уже выполненные действия откатываются.

### 3. CSV Report Generator

Определяет распространённую кодировку и разделитель CSV, считает пропуски и уникальные значения, распознаёт числовые столбцы и создаёт автономный HTML-отчёт.

**Практическая ценность:** быстрая первичная проверка выгрузок из CRM, магазина или учётной системы.

**Надёжность:** пользовательские значения экранируются перед вставкой в HTML; ошибки файла и формата выводятся понятным сообщением.

## Подход к работе

1. Фиксирую входные данные и ожидаемый результат.
2. Согласовываю небольшой проверяемый этап.
3. Показываю рабочую версию.
4. Проверяю граничные случаи и ошибки.
5. Передаю исходники вместе с инструкцией запуска.

Контакты и ссылка на опубликованный репозиторий указываются в профиле фриланс-биржи.
