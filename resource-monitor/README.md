# Windows Resource Monitor

Лёгкое оконное приложение показывает текущую загрузку процессора, оперативной памяти и системного диска. Историю измерений можно сохранить в CSV и затем открыть в Excel.

![Окно программы](screenshot-cropped.png)

## Возможности

- обновление показателей каждую секунду;
- пауза и продолжение мониторинга;
- хранение последних 60 минут измерений;
- сохранение CSV в кодировке, совместимой с Excel;
- работа без сторонних библиотек;
- понятное сообщение при ошибке чтения системных данных.

## Запуск

Из корня всего портфолио:

```powershell
py -3 resource-monitor/app.py
```

Или из папки проекта:

```powershell
py -3 app.py
```

Поддерживаются Windows 10/11 и Python 3.10+. На Linux и macOS программа не запускается, потому что получает показатели через Windows API.

## Результат

Кнопка «Сохранить CSV» создаёт журнал со столбцами `timestamp`, `cpu_percent`, `memory_percent` и `disk_percent`.
