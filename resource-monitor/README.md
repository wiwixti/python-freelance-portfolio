# Windows Resource Monitor

Небольшое оконное приложение показывает текущую загрузку процессора, оперативной памяти и системного диска. Историю измерений можно сохранить в CSV.

## Возможности

- обновление показателей каждую секунду;
- пауза и продолжение мониторинга;
- сохранение последних 60 минут измерений;
- работа без сторонних библиотек;
- понятные сообщения об ошибках.

## Запуск

```powershell
python app.py
```

Поддерживается Windows 10/11 и Python 3.10+.
